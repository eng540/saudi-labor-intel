# خرائط تدفق الإجراءات (Mermaid)

كل خريطة ملف ماركداون يحوي مخطط Mermaid — تُعرض مباشرة على GitHub.
المصادر الأساسية لكل خريطة مذكورة برؤوس المعرفات داخل الملف (مثل LIFE-xx من `docs/05-iqama-lifecycle.md`).

| الخريطة | المسار | تغطي |
|---|---|---|
| 1. من تأشيرة العمل إلى الإقامة | `01-visa-to-iqama.md` | المحور 4 (LIFE-01..12) |
| 2. دورة التجديد والخروج والعودة والخروج النهائي | `02-renewal-exit.md` | المحور 9 (RNEW-xx) |
| 3. نقل الخدمات (السيناريوهات والحالات) | `03-transfer-services.md` | المحوران 6-7 (TRN-xx) |
| 4. توظيف وتشغيل العامل في منشأة قائمة | `04-employer-onboarding.md` | المحور 11 (OPS-xx) |

قواعد الرسم الموحدة:
- عقدة خضراء = إجراء مكتمل موثق · صفراء = موثق جزئياً · حمراء = حالة تعثر/مخالفة.
- كل عقدة تحمل معرف المصدر بين قوسين عند توفره.
