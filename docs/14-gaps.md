# 14 — تقرير الفجوات الموحد (المعلومات غير المتحققة)

> **تاريخ الإعداد:** 2026-11-17 · يُحدَّث مع كل جولة تحقق جديدة · المصدر: أقسام «فجوات» في الأدلة 02–13 + سجل التحقق المركزي.
> **قاعدة:** أي حكم في هذه القاعدة موسوم «غير متحقق حتى الآن» لا يُستخدم في المشورة قبل استكمال تحققه من مصدر رسمي نصي.

## 1) قيود أدوات التحقيق التي سببت الفجوات (شفافية منهجية)

| القيد | الأثر | العلاج المطبق |
|---|---|---|
| أداة `web_search` معطلة (خطأ إعداد 404) | صعوبة الاكتشاف | جلب مباشر + محرك DuckDuckGo HTML |
| qiwa.sa / muqeem.sa / absher / gosi / musaned: مواقع SPA تفاعلية | لا تُستخرج نصوصها آلياً | العزو إلى صفحات HRSD النصية وأدلة PDF الرسمية وأرشيف الصفحات الرسمية |
| PDFs ممسوحة ضوئياً (جدول المخالفات 2026، بعض قرارات التوطين) | تعذر استخراج الجداول | موثقة بوجودها وأهم أحكامها النصية القابلة للقراءة |
| laws.boe.gov.sa محجوب من بيئة بعض الباحثين | تعذر سحب نصوص الأنظمة مباشرة | العزو إلى النص المجمّع الرسمي المتطابق (PDF وزارة الموارد) وأم القرى |
| حدّ نافذة الجلب لكل جولة | بقاء بعض الصفحات غير مُجلة | وسم صريح وتحديد «أولوية التحقق القادمة» أدناه |

## 3) الفجوات بحسب المحور (ملخص مجمع)

| المحور | أبرز الفجوات الموسومة في الدليل |
|---|---|
| 1 الجهات (docs/02) | مسمى «مجمع الأعمال الجوازي» و«منصة مقين» غير متحققين؛ مشغّل مدد؛ خدمات مساند التفصيلية؛ إعادة تسمية SCFHS |
| 2 التأشيرات (docs/03) | رسوم التأشيرات الحكومية؛ صلاحية الدخول؛ تحويل الزيارة إلى إقامة (لا نص رسمي)؛ تأشيرة عمل حر للأجانب |
| 3 الكيانات (docs/04) | شروط الأفراد في مساند؛ تصنيف أحجام منشآت الأعمال؛ قائمة دول الاستقدام الحالية؛ قواعد MISA والسجل التجاري |
| 4 دورة الإقامة (docs/05) | مهلة 90 يوماً/غرامة 500 (ثانوي)؛ رسوم السفارات؛ رسوم إفادة؛ فئات التأمين أ/ب/ج نصاً |
| 5 الرسوم (docs/06) | رسوم تغيير المهنة (تعارض)؛ انعكاس التغيير على الإقامة؛ نسب توطين المبيعات/الأسنان |
| 6 الكفالة (docs/07) | اللائحة التنفيذية نصاً؛ مهل النقل في قوى؛ رسوم النقل رسمياً (الثابت: تحملها المنشأة الجديدة م40/3) |
| 7 سيناريوهات النقل (docs/08) | سيناريوهات فرد↔منشأة (6،7،8،9) تفصيلاً؛ رخصة جديدة أم تحديث عند النقل؛ خلافة ملكية المنشأة |
| 8 المهن (docs/09) | جداول 97528 الزمنية (مصوّرة)؛ قرارات توطين 2020–2021 الأصلية؛ ربط المهنة بالنشاط في قوى |
| 9 التجديد/الخروج (docs/10) | رسوم تمديد الخروج والعودة؛ توقيت توقف المقابل عند الخروج النهائي؛ إيقاف الخدمات البنكية |
| 10 البطاقات الصحية (docs/11) | نص لائحة 33232 الكامل وقائمة المهن عالية الخطورة؛ مراحل النفاذ المطلقة |
| 11 التشغيل (docs/12) | طبقات غرامات جدول 2026 (OCR)؛ قائمة الأعياد في اللائحة؛ قواعد الحضور والانصراف وارتباطها بالحوافز؛ تفاصيل GOSI النافذة |
| 12 القرارات (docs/13) | أرقام توطينات 2021–2023؛ قرار تأسيس المقابل المالي وجدوله؛ أنظمة الصحة والتأمينات (71/248/السقف 18,000) |

## 5) تصحيحات فرضيات التكليف (ما انكشف خطؤه)

1. لا يوجد «نظام عمل م/39» — الصحيح م/51 المعدل بم/44.
2. chs.gov.sa وsce.org.sa وefada.sa «حكومية» — تصحيحها في docs/02 وdocs/05.
3. «قرار 310 و1443هـ» — الصحيح 1434هـ.
4. رسوم رخصة العمل 10,200 ريال — الصحيح حالياً 100 ريال/سنة (م/8 1415هـ + قرار 325).
5. «إفادة» منصة حكومية — efada.sa منصة مشغل خاص مربوطة بخدمة وزارة الصحة.

## 6) خطة التحقق القادمة (لمن يحدّث هذه القاعدة)

1. جلسة تحقق بحساب قوى فعلي: رسوم تغيير المهنة، شروط النقل الذكي، شروط المنشآت التفصيلية، جدول الرسوم الحي.
2. OCR على PDFs الممسوحة: جدول المخالفات 112377، قرار 41454 (جداوله)، 97528.
3. سحب نصوص: اللائحة التنفيذية لنظام العمل، نظام العمالة المنزلية ولائحتها، أنظمة الصحة والتأمينات، صفحات رسوم الخارجية (بحساب مسجل).
4. توثيق توطينات 2021–2023 من أم القرى الأرشيفية.
5. دليل مستخدم مساند (شروط الأفراد بالأرقام) وبلدي (البطاقة الصحية).
