# 05 — دورة حياة إصدار الإقامة: من تأشيرة العمل إلى هوية المقيم (المحور 4)

> تاريخ الاطلاع الموحّد لكل المصادر في هذا الملف: **2026-11-17**.
> قاعدة التوثيق: كل حكم نظامي أو رسم أو مدة يحمل معرّفًا [LIFE-xx] + مصدرًا + تاريخ الاطلاع + الحالة (موثق / موثق جزئياً / غير متحقق حتى الآن).
> ما لم يتحقق من مصدر رسمي مُجلب وُسم صراحة "غير متحقق حتى الآن"؛ لا أرقام مُختلقة.

## النطاق
مسار العامل الوافد **المهني** (على كفالة منشأة) من إصدار تأشيرة العمل حتى إصدار هوية المقيم، مع فروقات العمالة المنزلية حيثما وردت. يغطي: التأشيرة ← السفارة ← الفحص الطبي الخارجي ← الدخول ← الفحص الطبي الداخلي ← التأمين ← التسجيل في الأنظمة ← رخصة العمل ← الإقامة ← توثيق العقد ← اشتراطات المهنة. (التجديد والخروج في الملف 10.)

## المصطلحات

| المصطلح | التعريف العمل |
|---|---|
| تأشيرة العمل | تأشيرة دخول من أجل العمل تصدر لطلب صاحب العمل عبر قوى وتُفوَّض عبر وزارة الخارجية/سفاراتها — تسبق الإقامة ولا تعني حق العمل الدائم [LIFE-01][LIFE-02] |
| رقم الحدود | رقم مؤقت يُمنح للوافد عند الدخول قبل إصدار الإقامة، تُبنى عليه المعاملات (ممارسة معتادة — وسم ثانوي) [LIFE-05] |
| الإقامة (هوية مقيم) | رخصة الإقامة النظامية للوافد — تُصدر عن المديرية العامة للجوازات عبر المنصات [LIFE-10] |
| رخصة العمل | إذن مزاولة العمل لغير السعودي — **لا تُمنح الإقامة ولا تُجدد إلا بعد الحصول عليها** [LIFE-09] |
| المقابل المالي | رسم شهري على المنشأة عن العامل الوافد (700/800 ريال بحسب الوضع) [LIFE-01][LIFE-09] |
| إفادة | منصة التقارير الطبية للوافدين المرتبطة بوزارة الصحة والجوازات؛ efada.sa منصة مشغّل خاص مربوطة بالخدمة [LIFE-06] |
| وافد | برنامج الفحص الطبي قبل القدوم تحت مظلة المجلس الصحي الخليجي (wafid.com) [LIFE-04] |

## فجوات ومعلومات غير متحققة (المحور 4)
1. مهلة 90 يوماً وغرامة 500 ريال لتأخير إصدار الإقامة: لا صفحة رسمية مُجلة تُثبت الرقمين (صفحة رسوم الجوازات تُجلب مقصوصة) — متحقق ثانوياً فقط.
2. رسوم/مدد السفارات ومركز التأشيرات (رسوم إصدار التأشيرة عند السفارة، مدد الحجز): غير متحقق حتى الآن.
3. رسوم الفحص الطبي الداخلي (إفادة) وتصنيف المراكز المعتمدة: غير متحقق حتى الآن.
4. فئات وثائق التأمين (أ/ب/ج) وتفاصيل الإلزام قبل الإقامة: غير متحقق رسمياً (chi.gov.sa صفحات لا تُجلب كاملة).
5. نسبة 2% للأخطار المهنية على صفحة رسمية مُجلة مباشرة: غير متحقق (نقل ثانوي متطابق عن المؤسسة).
6. شروط قوى التفصيلية (حيازات التأشيرات، النطاقات، رسوم القياس): SPA لا يُجلب — غير متحقق.
7. نص المادة الدقيقة في نظام الضمان الصحي التعاوني الخاصة بإلزام صاحب العمل: غير متحقق حتى الآن (الرابط الرسمي موجود).
8. مدة استلام الجواز بعد الدخول وآلية "رقم الحدود": غير متحقق رسمياً.
